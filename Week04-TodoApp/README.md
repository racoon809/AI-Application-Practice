단계별 프롬프트 전략으로 Claude Code에서 만든 할 일 관리 앱의 **4주차 제출 원본**입니다.
5주차(자동 분류)와 6주차(데스크톱 레이아웃) 고도화 버전은 [`Week05-06-SmartTodo`](../Week05-06-SmartTodo/)에 있습니다.

## 실행
1. [`index.html`](index.html)을 더블 클릭합니다. (Chrome·Edge 권장, 설치·서버 불필요)
2. 처음 열면 빈 목록(0개)으로 시작합니다.
3. GitHub Pages: https://racoon809.github.io/AI-Application-Practice/Week04-TodoApp/

## 파일
| 파일 | 내용 |

## 새로고침해도 등록한 일정이 남습니다
- 할 일을 추가·수정·완료·삭제할 때마다 브라우저 `localStorage`의 `myTasks.tasks`에 바로 저장합니다.
- 페이지를 열 때 `TaskStore.load()`가 저장된 목록을 다시 불러오므로, **새로고침하거나 브라우저를 껐다 켜도 일정이 그대로 남습니다.** (PRD의 "새로고침 후에도 데이터 유지" 요구)
- 완료 체크 상태, 카테고리, 우선순위, 직접 정렬한 순서까지 함께 저장됩니다.
- 같은 앱을 탭 두 개로 열면 한쪽에서 바꾼 내용이 다른 탭에도 반영됩니다.
- 새로고침할 때 **비워지는 것은 '새 일정' 입력 폼뿐**입니다. 쓰다 만 글자, 카테고리·우선순위 선택값이 남아 다음 일정에 섞이지 않도록 일부러 초기화합니다.
- 서버나 DB가 없으므로 데이터는 그 브라우저에만 있습니다. 다른 사람·다른 브라우저와 섞이지 않습니다.

직접 확인하는 방법
1. 할 일 2~3개를 추가하고 하나를 완료 체크합니다.
2. `F5`로 새로고침합니다.
3. 목록과 완료 체크가 그대로 있고, 입력창만 비어 있는지 확인합니다.

처음 상태로 되돌리려면 **[완료 항목 삭제]**로 지우거나, 시크릿 창에서 열거나, `F12` → Application → Local Storage에서 `myTasks.*` 키를 지웁니다.

## 주요 기능 (5단계 프롬프트)
| 단계 | 기능 |
|---|---|
| 1. 기본 구조 | 할 일 추가 · 완료 체크 · 삭제, 저장 |
| 2. 카테고리·UI | 업무 / 개인 / 공부 분류, 우선순위(높음·보통·낮음), 카테고리 필터 |
| 3. 진행률 대시보드 | 전체 진행률, 카테고리별 진행률, 오늘 추가한 개수, 더블 클릭 수정 |
| 4. 다크 모드·고급 기능 | 다크 모드, 완료 항목 일괄 삭제(확인 창), 단축키, 삭제 실행 취소 토스트 |
| 5. 완성·최적화 | 정렬 6종(최신·오래된·카테고리·우선순위·완료 상태·드래그 직접 정렬), 오늘의 명언, JSON 내보내기/가져오기 |

## 단축키
| 키 | 동작 |
|---|---|
| `Alt + N` | 새 일정 입력 |
| `Esc` | 입력 폼 초기화 |
| `Alt + D` | 다크/라이트 모드 |
| `Alt + 1` ~ `Alt + 4` | 전체 / 업무 / 개인 / 공부 필터 |
| 더블 클릭 또는 `Enter`·`F2` | 할 일 수정 |
| 드래그 손잡이에서 `↑` `↓` | 직접 정렬 순서 이동 |

## 자체 점검
브라우저 개발자 도구(F12) 콘솔에서 `evaluateApp()`을 실행하면 저장소 읽기/쓰기, 새로고침 후 데이터 유지 등 항목별 점검 결과가 표로 나옵니다.
