`quiz-data.js`에 새 퀴즈 문제를 **1개** 추가해 줘.

## 인수
- `$1` = 카테고리 (한국사 | 과학 | 지리 | 일반상식)
- `$2` = 난이도 (easy | medium | hard) — `쉬움/보통/어려움`, `초급/중급/고급`으로 입력해도 각각 easy/medium/hard로 바꿔서 처리
- 인수가 없거나 잘못되면 사용법을 보여 주고 멈춰.

## 작성 절차
1. `quiz-data.js`를 읽고 **기존 문제와 같은 형식**(id, category, difficulty, question, options, answer, hint, explanation, basis)을 확인해.
2. 같은 카테고리의 기존 문제와 **주제가 겹치지 않는** 문제를 정해.
3. CLAUDE.md의 「퀴즈 문제 교차 검증 가이드라인」 4가지를 반드시 지켜.
   - 정답은 하나뿐 / 최상급 표현에는 측정 기준 / 변할 수 있는 정보는 시점·범위 명시 / 논란 있는 내용은 주류 학설
4. 정답 위치 분포를 확인해서 **가장 적게 쓰인 위치**에 정답을 배치해.
5. 보기 4개는 모두 그럴듯하지만 정답은 하나만 맞도록 만들고, 중복 보기는 금지.
6. `id`는 현재 최댓값 + 1, 해당 카테고리 블록의 마지막에 추가해.

## 추가 전 확인
파일을 수정하기 전에 아래 형식으로 먼저 보여 주고 확인을 받아.

```
[미리보기] #41 · $1 · $2
Q. 문제
① 보기1  ② 보기2  ③ 보기3  ④ 보기4
정답: ②  |  힌트: ...
해설: ...
가이드라인 체크: 정답 유일 ✅ / 최상급 기준 ✅ / 시점·범위 ✅ / 교차 검증 ✅ (확인한 근거 2가지)
```

확신할 수 없는 사실이면 문제를 만들지 말고 다른 주제를 제안해.
추가가 끝나면 전체 문제 수와 정답 위치 분포를 다시 알려 줘.
