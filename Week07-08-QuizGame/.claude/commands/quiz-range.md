`quiz-data.js` 파일을 읽고, `id`가 **$1번부터 $2번까지**인 문제를 검토해 줘.

## 입력 확인
- `$1`, `$2`가 숫자가 아니거나 `$1 > $2`이면 사용법(`/quiz-range 1 20`)을 알려 주고 멈춰.
- 존재하지 않는 번호가 포함되면 실제 있는 범위로 조정했다고 알려 줘.

## 문제별 검토
각 문제에 대해 다음을 표로 보여 줘.
1. 문제 번호, 카테고리, 난이도
2. 문제 내용 (한 줄 요약)
3. 정답 위치 (0~3번 보기 중 몇 번인지, 화면 표시 기준 ①~④도 함께)
4. CLAUDE.md 교차 검증 가이드라인 위반 여부 (간단히 ✅/⚠️)

## 분석
1. **난이도 분포**: easy/medium/hard 개수와 비율, 점수 환산(10/15/20) 평균과 표준편차
   - 너무 쉽거나 어려운 문제가 특정 구간에 몰려 있는지 확인
2. **정답 분포**: 0번·1번·2번·3번 보기가 정답인 개수와 비율
   - 목표는 각 25%. 한 위치가 40% 이상이거나 한 번도 정답이 아닌 위치가 있으면 ⚠️ 경고
3. **카테고리 분포**: 범위 안의 카테고리별 문제 수

## 출력
- 맨 아래에 「⚠️ 경고 사항」과 「권장 사항」을 정리해 줘.
  - 예) 정답 위치 편향을 줄이려면 어떤 문제의 보기 순서를 바꾸면 되는지 문제 번호로 제안
- 파일은 수정하지 말고 분석 결과만 보여 줘.
