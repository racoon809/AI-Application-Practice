# CLAUDE.md

이 파일은 이 저장소에서 작업하는 Claude Code에게 프로젝트 정보를 제공합니다.

## 프로젝트 개요
- 이름: 지식왕 도전 (Knowledge King Challenge) — 4지선다 상식 퀴즈 게임
- 과목: 인공지능활용실습 7~8주차 (Week07-08-QuizGame)
- 기술: 순수 HTML, CSS, JavaScript (빌드 도구 없음). `index.html`을 브라우저에서 바로 실행
- 카테고리: 한국사, 과학, 지리, 일반상식 — 각 10문제, 총 40문제

## 파일 구조
- `index.html` — 화면 구조 (시작 / 문제 / 결과 화면, 피드백 다이얼로그)
- `style.css` — 시험지 + OMR 답안지 콘셉트 스타일, 다크 모드
- `script.js` — 게임 로직 (모드, 채점, 타이머, 힌트, 순위 저장)
- `quiz-data.js` — 문제 데이터 `QUIZ_DATA` 배열 (문제 추가·수정은 이 파일에서만)
- `.claude/commands/` — 프로젝트 커스텀 명령어 (`/quiz-validate`, `/quiz-range`, `/quiz-add`)

## 문제 데이터 형식 (반드시 지킬 것)
```js
{
  id: 41,                       // 전체 일련번호, 중복 금지
  category: '한국사',            // '한국사' | '과학' | '지리' | '일반상식'
  difficulty: 'medium',         // 'easy'(10점) | 'medium'(15점) | 'hard'(20점)
  question: '...?',
  options: ['보기1', '보기2', '보기3', '보기4'],  // 반드시 4개, 중복 금지
  answer: 1,                    // 정답 인덱스 0~3
  hint: '정답을 직접 말하지 않는 힌트',
  explanation: '정답 근거 + 기준/시점',
  basis: '(선택) 가이드라인 적용 메모'
}
```
- 새 문제는 해당 카테고리 블록의 마지막에 추가하고 `id`는 전체 최댓값 + 1
- 정답 위치(answer 0~3)가 한쪽으로 몰리지 않도록 분포를 맞출 것 (각 25% 목표)

## 게임 규칙
- 클래식: 40문제 카테고리 순서대로 / 스피드 퀴즈: 무작위 20문제, 15초, 남은 초 보너스, 힌트 -5점 / 카테고리 도전: 한 분야 10문제
- 정답/오답 즉시 피드백(해설 포함), 종료 후 점수·정답률·분야별 결과, TOP 10 순위(localStorage)

# 퀴즈 문제 교차 검증 가이드라인

모든 문제 작성 시 확인 사항

1. 정답이 하나뿐인가?
   - 다른 해석 가능 시 조건 명시 (예: 면적 기준, 2024년 기준)

2. 최상급 표현에 기준이 있는가?
   - '가장 큰', '최초의' 등 표현에 측정 기준 명시

3. 시간과 범위가 명확한가?
   - 변할 수 있는 정보는 시점 명시
   - 지리적, 분류적 범위 한정

4. 교차 검증했는가?
   - 의심스러운 정보는 2개 이상 출처 확인
   - 논란 있는 내용은 주류 학설 기준

## 적용 예시
- 나쁜 예: "세계에서 가장 긴 강은?" → 아마존강/나일강 논쟁 존재
- 좋은 예: "전통적 측정 기준(주요 백과사전 기준)으로 세계에서 가장 긴 강은?" + 해설에 논쟁 안내
- 나쁜 예: "가장 높은 산은?" → 해발고도인지, 산 밑에서 정상까지 높이인지 불분명
- 좋은 예: "해발고도 기준으로 세계에서 가장 높은 산은?"
- 중요: 출처를 확인할 수 없는 정보로는 문제를 만들지 말 것. 확신이 없으면 문제를 만들지 말고 사용자에게 알릴 것
