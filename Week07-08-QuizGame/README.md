# 7~8주차 · 지식왕 도전 상식 퀴즈 (`Week07-08-QuizGame`)

> 제출자 서승하 (243441) · 컴퓨터공학과 3학년 · GitHub [racoon809](https://github.com/racoon809) · 제출일 2026-10-28 · [전체 목차](../README.md)

한국사 · 과학 · 지리 · 일반상식 4개 분야 **40문제**의 4지선다 퀴즈 게임입니다.
7주차에는 AI가 만든 문제의 할루시네이션을 막는 **교차 검증 가이드라인**을 `CLAUDE.md`에 저장했고,
8주차에는 게임 모드를 늘리고 문제 검증·추가를 **커스텀 명령어**로 자동화했습니다.

## 바로 실행하기
1. [`index.html`](index.html)을 더블 클릭합니다. (설치·서버 불필요, Chrome·Edge 권장)
2. 이름을 입력하고 게임 모드를 고른 뒤 **[게임 시작]**
3. 보기를 클릭하거나 키보드 `1`~`4`로 답을 고릅니다.
4. 바로 정답 여부와 해설이 나오고, **[다음 문제]**로 넘어갑니다.
5. 끝나면 점수, 정답률, 분야별 결과와 **명예의 전당 TOP 10**이 표시됩니다.

GitHub Pages: https://racoon809.github.io/AI-Application-Practice/Week07-08-QuizGame/

## 게임 규칙

| 모드 | 문제 | 규칙 |
|---|---|---|
| 클래식 | 40문제 | 한국사 → 과학 → 지리 → 일반상식 순서 |
| 스피드 퀴즈 | 무작위 20문제 | 문제당 15초, 남은 초만큼 보너스, 시간 초과는 오답, 힌트(`H` 키) 사용 시 -5점 |
| 카테고리 도전 | 선택한 분야 10문제 | 한 분야 집중 |

배점: 쉬움 10점 · 보통 15점 · 어려움 20점. 순위는 브라우저 `localStorage`에 저장됩니다.

## 문제 데이터와 검증
- 문제는 [`quiz-data.js`](quiz-data.js)의 `QUIZ_DATA` 배열에 있습니다. (분야별 10문제, 쉬움 16 · 보통 16 · 어려움 8)
- 정답 위치는 ①②③④에 각각 10개씩 고르게 배치했습니다.
- 최상급 표현에는 측정 기준을 붙였습니다. 문제마다 `basis` 필드에 적용한 가이드라인을 적어 두었습니다.

| 가이드라인 | 적용 예 |
|---|---|
| 정답이 하나뿐인가? | 「1919년 4월 **상하이**에서 수립된 정부」 → 다른 임시정부와 구분 |
| 최상급 표현에 기준이 있는가? | 「**전통적 측정 기준**으로 세계에서 가장 긴 강」 → 나일강 (해설에 아마존강 논쟁 안내) |
| 시간과 범위가 명확한가? | 「**2021년 지정번호 폐지 이전** 국보 제1호」, 「**한반도**에서 가장 높은 산」 |
| 교차 검증했는가? | 논란 있는 내용은 주류 학설 기준, 해설에 근거 수치 명시 |

전체 가이드라인: [`CLAUDE.md`](CLAUDE.md) 「퀴즈 문제 교차 검증 가이드라인」

## 커스텀 명령어 사용법 (8주차)
`Week07-08-QuizGame` 폴더에서 Claude Code를 실행하면 [`.claude/commands/`](.claude/commands/)의 명령어를 쓸 수 있습니다.
```bash
cd Week07-08-QuizGame
claude
```

| 명령어 | 하는 일 | 예시 |
|---|---|---|
| `/quiz-validate [카테고리]` | 최상급·모호한 표현을 찾아 기준 명시 여부 판정 (생략 시 전체) | `/quiz-validate` · `/quiz-validate 한국사` |
| `/quiz-range <시작> <끝>` | 지정 범위의 난이도·정답 위치·카테고리 분포 분석 | `/quiz-range 1 20` |
| `/quiz-add <카테고리> <난이도>` | 가이드라인을 지킨 새 문제를 미리보기 후 추가 | `/quiz-add 한국사 medium` |

- 명령어 파일을 새로 만들거나 고친 뒤에는 `/exit`로 종료하고 `claude`로 다시 시작해야 목록에 반영됩니다. `/help`로 확인할 수 있습니다.
- `/quiz-validate`, `/quiz-range`는 분석만 하고 파일을 고치지 않습니다. `/quiz-add`는 추가하기 전에 미리보기를 보여 주고 확인을 받습니다.

| 플레이스홀더 | 의미 | 예 |
|---|---|---|
| `$ARGUMENTS` | 명령어 뒤 입력 전체 | `/quiz-validate 한국사` → `한국사` |
| `$1`, `$2` | 공백으로 나눈 첫째·둘째 인수 | `/quiz-range 1 20` → `$1=1`, `$2=20` |

명령어 위치
| 종류 | 위치 | 적용 범위 |
|---|---|---|
| 프로젝트 명령어 (이번 실습) | `.claude/commands/` | 이 폴더에서만 |
| 전역 명령어 | `~/.claude/commands/` | 모든 프로젝트 |

## 실습 기록

### 7주차 · 할루시네이션 없는 AI 콘텐츠
1. claude.ai에서 PRD 작성
```
상식 퀴즈 게임을 만들려고 해. PRD를 작성해 줘.

게임 규칙:
- 4지선다 객관식 퀴즈
- 카테고리: 한국사, 과학, 지리, 일반상식
- 각 카테고리별 10문제씩 총 40문제
- 정답/오답 즉시 피드백
- 최종 점수 및 순위 기록
```
```
상식 퀴즈 게임을 클로드 코드로 구현할 수 있도록 PRD를 바탕으로 3단계 프롬프트를 정리해 줘.
```
2. `AI-Application-Practice/Week07-08-QuizGame`에서 `claude` → `/init` → 1단계 프롬프트 실행 → `index.html`로 테스트
3. `/memory` → **Project memory** → CLAUDE.md에 교차 검증 가이드라인 추가
```
현재 프로젝트의 CLAUDE.md 내용을 확인해 줘.
```
4. `/clear`로 대화를 지운 뒤 가이드라인만으로 다시 점검
```
지금까지 만든 문제를 방금 저장한 가이드라인을 참고해서 점검해 줘. 가이드라인에 맞지 않은 퀴즈와 정답이 있다면 이에 맞게 수정해 줘.
```
> `/compact`는 대화를 요약해 남기고, `/clear`는 대화를 완전히 지웁니다. 규칙은 CLAUDE.md에 있으므로 `/clear` 후에도 유지됩니다.

### 8주차 · 게임 확장과 커스텀 명령어
- 2단계 프롬프트로 게임 모드 3종 추가 (스피드 퀴즈 15초, 힌트 감점)
- 명령어 폴더와 명령어 파일 생성에 사용한 프롬프트
```
현재 프로젝트에 커스텀 명령어 폴더를 만들어 줘. .claude/commands 디렉터리를 생성하고 구조를 보여줘.
```
```
.claude/commands/quiz-validate.md 파일을 만들어 줘. 퀴즈 문제 중에서 '가장', '최초', '최대' 같은 최상급 표현이 있는지 찾아서 목록으로 보여줘.
```
```
.claude/commands/quiz-validate.md를 다음과 같이 수정해 줘.

사용자가 카테고리를 지정하면 해당 카테고리의 문제만 검증하고,
지정하지 않으면 전체 문제를 검증해 줘.
$ARGUMENTS에 입력된 값을 카테고리로 사용하면 돼.

검증할 때는 '가장', '최초', '최대' 같은 모호한 표현이 있는지 찾아서
어떤 기준을 명시해야 하는지 알려 줘.
```
```
.claude/commands/quiz-range.md를 생성해.

$1번부터 $2번까지의 문제를 검토하는 기능을 만들어 줘.
문제의 난이도와 정답 분포를 확인하게 해 줘.
```
```
.claude/commands/quiz-add.md를 생성해.

새 퀴즈를 추가하는 명령어를 만들어 줘.

기존 퀴즈들과 같은 형식으로 만들고, 검증 가이드라인을 꼭 지키게 해 줘.
```
