# PRD: 프리랜서 마케터 포트폴리오 웹페이지

> 2주차 실습 산출물 · 5W1H 기본 질문 템플릿으로 클로드와 대화하며 작성한 제품 기획서

## 0. PRD 작성에 사용한 프롬프트 (기본 질문 템플릿)

```
포트폴리오 웹페이지를 만들려고 해.                                   ← 무엇(What)
주요 기능은 채용 담당자가 30초 안에 내 역량을 파악할 수 있는
임팩트 있는 구성이야.                                                 ← 구체적인 기능 설명
프리랜서 전환을 준비하는 마케터를 위한 것이고,                        ← 누구(Who)
경쟁력 있는 지원자로 보이기 위해 필요해.                              ← 왜(Why)
어떻게 구현하면 좋을지 기술적인 방향과 함께 구체적인 PRD를 작성해 줘. ← 구현 방안(How)
```

## 1. 개요 (5W1H)

| 항목 | 내용 |
|---|---|
| Why (목적) | 프리랜서 전환 시 클라이언트·채용 담당자에게 경쟁력 있는 지원자로 보이기 |
| Who (대상) | 3년 차 퍼포먼스/콘텐츠 마케터 본인, 열람자는 채용 담당자·잠재 클라이언트 |
| What (기능) | 30초 안에 역량이 파악되는 원페이지 포트폴리오 |
| When (사용 시점) | 지원서·제안서 제출 시 링크 첨부, 미팅 전 사전 열람 |
| Where (사용 환경) | 데스크톱·모바일 브라우저 (반응형) |
| How (구현) | `index.html`(구조·동작) + `style.css`(디자인), 외부 프레임워크 없음, 클로드 아티팩트로 게시 |

## 2. 핵심 목표 (열람 시간 기준)

- **3초**: 이름·포지션·대표 성과(ROAS 200%)가 첫 화면에 보인다.
- **10초**: 숫자로 된 스펙 요약(캠페인 수, 매출 기여)을 확인한다.
- **30초**: 대표 케이스 3건과 연락 방법까지 도달한다.

## 4. 콘텐츠 (2단계 '기능'에서 제공한 실제 데이터)

- 3년 차, 퍼포먼스/콘텐츠 마케팅 전문가
- 핵심 성과: ROAS 200%, 25개 캠페인, 연 8억 매출 기여
- 포지션 변화: 주니어(2023) → 퍼포먼스 마케터(2024) → 매니저+자문(2025)
- 스킬: 퍼포먼스 75%, 콘텐츠 70%, 데이터 분석(GA4) 65%
- 케이스: 이커머스 월 광고비 1천만 원·ROAS 200% / 스타트업 인스타 팔로워 2천→8천(6개월) / 로컬 브랜드 블로그 방문자 500→3천(4개월)

## 5. 기능 요구사항

- 내비게이션 앵커 이동(부드러운 스크롤), 모바일에서는 CTA만 표시
- Before/After 지표를 막대 차트로 표현 (SVG, 외부 라이브러리 없음)
- 케이스 스터디 분야 필터(전체/퍼포먼스/콘텐츠)
- 연락처 복사 버튼, 문의 폼 입력 검증
- 다크 모드 토글 (시스템 설정 자동 반영)

## 6. 비기능 요구사항

- HTML·CSS 두 파일, 외부 라이브러리 없음, 로딩 1초 이내, 360px 모바일 폭에서도 가로 스크롤 없음
- 섹션별 색상 톤 구분 (3단계 '디자인' 요구)
- 키보드 포커스 표시, 이미지·차트 대체 텍스트 제공

## 7. 완료 기준 (4단계 '점검' 체크리스트)

- [ ] PRD의 9개 섹션이 모두 존재하고 ID가 일치한다
- [ ] 모든 내부 링크가 해당 섹션으로 이동한다
- [ ] 모바일 폭에서 레이아웃이 1열로 정리된다
- [ ] 샘플 추천사·예시 연락처를 실제 정보로 교체했다
