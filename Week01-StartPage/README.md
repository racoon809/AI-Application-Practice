# 1주차 · 나만의 시작 홈페이지 (`Week01-StartPage`)

> 제출자 서승하 (243441) · 컴퓨터공학과 3학년 · GitHub [racoon809](https://github.com/racoon809) · 제출일 2026-10-28 · [전체 목차](../README.md)

**실행:** [`index.html`](index.html) 더블 클릭 (설치 불필요)

클로드 아티팩트에서 자연어 프롬프트만으로 만든 개인 시작 페이지입니다. HTML·CSS·JS가 `index.html` 한 파일에 들어 있습니다.

## 기능
| 위젯 | 구현 |
|---|---|
| 현재 시간 | 1초마다 갱신되는 디지털 시계, 한국어 날짜·요일, 시간대별 인사 |
| 구글 검색바 | 입력어로 `google.com/search?q=` 새 탭 열기 |
| 오늘의 날씨 | Open-Meteo 공개 API(키 불필요), 서울·목포·부산·광주·제주 선택, 4일 예보 |
| 최신 기술 뉴스 | Hacker News 공개 API 인기 글 6개 (15분마다 갱신) |
| 오늘의 할 일 | 추가·완료·삭제, 브라우저 localStorage 저장 |
| 공통 | 메모지 2열 배치(모바일 1열), 다크 모드, 외부 연결이 막히면 예시 데이터/뉴스 사이트 바로가기로 대체 |

```
```

```
```

```
```
오늘의 할 일 목록을 추가해 줘.
```
```
[현재 시간], [오늘의 할 일], [오늘의 날씨], [최신 기술 뉴스] 아이템을 한 열에 두 개씩 배치하고,

## 웹 게시 방법
### A. 클로드 아티팩트로 게시 (강의 방식)
1. claude.ai 왼쪽 사이드바 **[아티팩트] → [+ 새 아티팩트] → [앱 및 웹사이트]**
2. 위 프롬프트로 제작하거나, 이 `index.html` 내용을 붙여 넣고 "이 코드로 아티팩트를 만들어 줘" 요청
3. 아티팩트 상단 **[게시] → [게시 및 링크 복사] → [링크 복사]**
4. 복사한 링크를 브라우저 주소창에 붙여 넣어 확인
> 아티팩트 환경은 외부 API 요청을 막을 수 있습니다. 이때 날씨는 '예시 데이터'로, 뉴스는 실제 뉴스 사이트 바로가기로 표시됩니다.

### B. GitHub Pages로 게시 (실시간 날씨·뉴스 동작)
1. 저장소 **Settings → Pages → Branch: `main` / `/(root)` → Save**
2. 1~2분 뒤 https://racoon809.github.io/AI-Application-Practice/Week01-StartPage/ 접속 (루트의 `.nojekyll` 파일 덕분에 파일이 그대로 게시됨)
